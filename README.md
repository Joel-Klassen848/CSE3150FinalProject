# CSE3150FinalProject

For our C++ project, we will be using network programming to create a packet sniffer. The project has the potential to be very manual or very abstracted, so we will try to strike the balance so we can learn without relying too heavily on preexisting libraries. We plan to use the **libpcap library** to capture packets and then parse the headers manually. We will implement our own detection logic and try to do as much as we can manually, and try to implement a client/server system to test it by generating traffic and sending malformed packets if we have time.

We plan to create a GUI as per the instruction sheet, so that the application is easier to present and interact with. This will most likely be handled by AI, as we don’t want to spend unnecessary time programming a front-end component that Claude Code could make faster and better, especially since neither of us are very interested in front-end development. This will allow us to spend our time learning and applying socket programming and cybersecurity principles in the C++ language. 

Οur primary resource will be Beej’s Guide to Network Programming, which, although written for C programming, will be equally useful for a C++ project since the concepts transfer directly from C to C++ code. We will also use AI to review our code for bugs and memory problems, and as a learning resource, since we do not have much prior experience with C++ network programming. We will use Wireshark to compare the packets that we analyze with a known packet analyzer.
